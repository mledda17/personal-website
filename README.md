# marcoledda.it

Personal academic website of Marco Ledda, served by GitHub Pages at
[www.marcoledda.it](https://www.marcoledda.it).

The site is plain HTML/CSS generated by a small Python script (`build.py`,
standard library only, Python 3.11+). Every push to `main` rebuilds and deploys
the site through GitHub Actions.

## Where things are

| What | File |
| --- | --- |
| Profile, bio, links, research interests, co-author links | `content/site.toml` |
| Publications (BibTeX, abstract, PDF, logo, ...) | `content/publications.toml` |
| News | `content/news.toml` |
| Talks and `/slides/<id>/` pages | `content/talks.toml` |
| Teaching | `content/teaching.toml` |
| Page layout (header, footer) | `templates/base.html` |
| Styles / scripts | `assets/css/style.css`, `assets/js/site.js` |
| Paper PDFs / slide PDFs | `files/papers/`, `files/slides/` |
| CV and M.Sc. thesis | `files/cv/`, `files/thesis/` (thesis readable at `/thesis/`) |
| Venue logos, paper thumbnails, photo | `assets/logos/`, `assets/thumbs/`, `assets/img/` |

## Common edits

**Add a news item**: add a block to `content/news.toml`:

```toml
[[news]]
date = "2027-03"
text = "Our paper [[C5]] has been accepted at **ECC 2027**. [Slides](slides/ecc2027/)"
```

`**bold**`, `*italic*`, `[text](url)` and `[[C5]]` (link to a paper) are supported.
Items are sorted by date automatically; future dates get an "Upcoming" tag.

**Add a publication**: copy an existing `[[publication]]` block in
`content/publications.toml`, give it the next label (`C5`, `J1`, `A2`, ...) and
the right `category` (`conference`, `journal` or `preprint`). Then:

1. put the PDF in `files/papers/` and set `manuscript`;
2. optionally add a venue logo in `assets/logos/` (`logo`, `logo_url`);
3. optionally add a first-page thumbnail for the homepage (macOS):
   `sips -s format jpeg -s formatOptions 78 -Z 400 files/papers/NAME.pdf --out assets/thumbs/C5.jpg`
4. set `selected = true` to show it under "Selected publications" on the homepage.

The Type and Year filters on the Publications page are built automatically.

When a preprint gets published, change its `category`, give it a `J`/`C` label,
remove `status = "under review"` and `logo_note`, and add the `doi`.

**Add a talk**: add a `[[talk]]` block to `content/talks.toml` with a `slug`
and the PDF in `files/slides/`. The slides page is created at
`/slides/<slug>/` (the URL to print on the title slide). If `paper` is set,
the paper automatically gets a *Slides* button.

**Profile links**: fill `scholar`, `orcid`, `linkedin`, `cv`, ... in
`content/site.toml`; empty values are hidden.

## Preview locally

```sh
python3 build.py serve      # http://localhost:8000
```

The build stops with a clear message if a referenced file or paper label does
not exist.

## Deployment (one-time setup)

1. **GitHub → Settings → Pages → Build and deployment → Source: GitHub Actions.**
2. **Settings → Pages → Custom domain:** `www.marcoledda.it`, then tick
   *Enforce HTTPS* once the certificate is ready. (With Actions deployments the
   domain is configured here; the `CNAME` file is kept only as a reference.)
3. At the DNS provider of `marcoledda.it`:
   - `www` → `CNAME` → `mledda17.github.io.`
   - apex `marcoledda.it` → `A` records `185.199.108.153`, `185.199.109.153`,
     `185.199.110.153`, `185.199.111.153`
     (optionally `AAAA` `2606:50c0:8000::153`, `2606:50c0:8001::153`,
     `2606:50c0:8002::153`, `2606:50c0:8003::153`).
4. Recommended: verify the domain in your GitHub account settings
   (*Settings → Pages → Add a domain*) to protect it from takeover.

Old WordPress URLs `/presentations/` and `/tutoring/` redirect to `/talks/` and
`/teaching/`.
